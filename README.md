# هم‌تماشا (HamTamasha) - اپلیکیشن تماشای گروهی فیلم با هسته LibVLC

اپلیکیشن اختصاصی سینمای مشترک هماهنگ با سرور `watch.manageyar.ir` و بهره‌گیری از هسته رسمی VLC برای پخش روان فایل‌های سنگین MKV و 4K بدون افت کیفیت، بدون باگ صدا و بدون مصرف پهنای باند سرور.

## امکانات
- پخش محلی فایل‌های ویدیو از حافظه گوشی (MKV, MP4, AVI, WebM)
- پشتیبانی از تمام کدک‌های صوتی (EAC3, AC3, Dolby Digital, DTS, AAC)
- هماهنگی خودکار توقف، پخش و جلو/عقب کشیدن
- زیرنویس فارسی (SRT, VTT, ASS)
- شمارش معکوس ۳ ثانیه‌ای برای شروع هم‌زمان
- چت متنی شناور
- مصرف اینترنت سرور نزدیک به صفر
